# Level A Content System

## Goal
Level A should not feel like the same screen with different text.
It should teach through varied visual missions while keeping the learning loop simple.

Core loop:
Listen → Look → Tap → See Result → Hear Word → Optional Imitation

## Mission Types

### A. Find One
Goal: object recognition

Examples:
- หาแอปเปิล
- หากล้วย
- หาลูกบอล
- หารถ

Layout:
Large object grid

### B. Find by Color
Goal: color recognition

Examples:
- หาของสีแดง
- หาของสีฟ้า
- หาของสีเหลือง

Important:
Do not always map one color to one fixed object.
Each color mission should include multiple objects and color distractors.

Example Red Mission:
- red ball
- red car
- strawberry
- blue cup
- yellow duck
- green leaf

### C. Pick Two
Goal: early quantity + multi-selection

Examples:
- เลือกผลไม้ 2 อย่าง
- เลือกของเล่น 2 อย่าง

### D. Find by Category
Goal: categorization

Examples:
- เลือกผลไม้
- เลือกของเล่น
- เลือกของใช้ในห้องน้ำ

### E. Big / Small
Goal: comparison

Examples:
- หาอันใหญ่
- หาอันเล็ก

### F. Same / Different
Goal: visual discrimination

Examples:
- หาอันที่เหมือนกัน
- หาอันที่ต่างจากเพื่อน

## Level A Rules
- Audio-first
- No reading required
- No arithmetic symbols
- No harsh wrong state
- Tapping non-target items can still teach something
- Visual variety matters
- One clear learning goal per mission
- English is exposure + imitation, not assessment
