# Art Direction

## Style
Soft 3D Toy World

## Visual Feel
- Cute
- Premium
- Warm
- Safe
- Playful
- Original
- Soft clay / toy-like 3D forms

## Environment
Minimal visual clutter.
Learning clarity is more important than decoration.

## Shapes
- Rounded
- Soft
- Friendly
- No visually aggressive sharp elements

## Objects
- Easy to recognize instantly
- Clear silhouettes
- Large enough for young children
- Consistent proportions and lighting

## UI
- Large touch targets
- Rounded cards and buttons
- Minimal text
- High visual hierarchy
- Avoid strong red error states

## Core Rule
Learning clarity > decoration.
