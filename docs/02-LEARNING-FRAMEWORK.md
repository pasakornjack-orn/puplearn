# Learning Framework

## Target Age
3–7 years

## Principle
Skills should be integrated inside a meaningful situation.

Example:
Read/listen to a shopping mission → understand the task → choose products → calculate budget → answer in English.

## Skill Areas

### Thai
- Listen and follow instructions
- Recognize words
- Read simple instructions
- Follow 1–3 step instructions

### Logic
- Matching
- Categorization
- Cause and effect
- Constraint solving
- Decision making

### Math
- Counting
- Quantity
- Comparison
- Addition
- Money
- Remaining amount

### English
- Everyday vocabulary
- Object recognition
- Simple phrases
- Usage in context

## Adaptive Principle
Age is a guide, not the only difficulty control.
Difficulty should adapt to demonstrated ability.
