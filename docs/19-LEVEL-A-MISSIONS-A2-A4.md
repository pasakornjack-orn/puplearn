# Level A Expansion Missions — A2 / A3 / A4

## Goal
Expand Level A with 3 additional missions that follow the validated toddler-friendly learning loop:

Listen → Look → Tap → See Result → Hear Word → Optional Imitation

These missions are for children around age 3–4 who may not yet read.

# A2 — Find the Banana
## Mission
Bingo says:
"ช่วย Bingo หากล้วยหน่อย!"

## Products Shown
- Apple
- Banana
- Soap
- Toothbrush

## Rules
- No prices
- No budget
- No math
- No harsh wrong feedback
- Child may tap any object

## Non-target Tap Behavior
If child taps another object:
- animate the object
- identify the object briefly if practical
- Bingo gently reminds the child to find Banana

## Correct Target
If Banana is tapped:
- Banana moves into the toy basket
- Bingo reacts positively
- Pillow teaches:
  "Banana!"
- child can replay the word

# A4 — Pick 2 Fruits
## Mission
Bingo says:
"ช่วย Bingo เลือกผลไม้ 2 อย่างหน่อย!"

## Products Shown
- Apple
- Banana
- Soap
- Toothbrush

## Correct Set
- Apple
- Banana

## Rules
- No prices
- No budget
- No arithmetic symbols
- allow curiosity taps
- basket remains visible and important

## Completion Rule
Mission completes only when both fruits are selected.

## Pillow Step
Pillow introduces both words with slow pacing:
"Apple!"
pause
"Banana!"

## Shared Level A Rules
- mobile-first
- large touch targets
- no reading dependency
- audio-first
- curiosity-friendly
- no harsh wrong state
- use the existing toy basket pattern
- reuse mascot roles
- preserve the Soft 3D Toy World visual style
