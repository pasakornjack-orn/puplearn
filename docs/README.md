# PupLearn Project Docs

Place this `/docs` folder inside the root of the project repository.

Recommended structure:

```text
puplearn/
├─ docs/
│  ├─ 01-PRODUCT-VISION.md
│  ├─ 02-LEARNING-FRAMEWORK.md
│  ├─ 03-ART-DIRECTION.md
│  ├─ 04-MASCOT-BIBLE.md
│  ├─ 05-MVP-SPEC.md
│  ├─ 06-MISSION-ENGINE.md
│  ├─ 07-UX-RULES.md
│  └─ 08-CURRENT-STATUS.md
├─ src/
├─ public/
└─ ...
```

Before implementing a feature, the coding agent should read the relevant files in `/docs`.

At the end of each session, update `08-CURRENT-STATUS.md`.
