# Age & Ability Path — PupLearn V1

## Principle
Age is a starting point, not a strict gate.
PupLearn should adapt from exploration to applied problem solving.

## Level A — Explore
Typical age: 3–4

Goal:
Listen, recognize, tap, discover, and connect words with objects.

Design:
- audio-first
- no reading required
- no arithmetic symbols
- one-step instructions
- simple familiar vocabulary
- tapping non-target items should still produce a useful response
- strong visual feedback

Examples:
- แตะแอปเปิล
- หาของสีแดง
- เลือกสุนัข
- หยิบกล้วย 1 ลูก

## Level B — Guided
Typical age: 4–5

Goal:
Follow simple multi-step instructions, count small quantities, categorize.

Examples:
- หยิบนม 2 กล่อง
- เลือกผลไม้ 2 อย่าง
- หาของสีแดงแล้วใส่ตะกร้า

## Level C — Think
Typical age: 5–6

Goal:
Compare, count, use simple quantities and constraints.

Examples:
- เลือกของที่ถูกกว่า
- ซื้อของ 2 อย่าง
- มี 10 บาท เลือกของที่ซื้อได้

## Level D — Challenge
Typical age: 5–7

Goal:
Integrated real-life problem solving.

Includes:
- reading instructions
- working memory
- budget constraints
- addition / remaining money
- contextual English usage
