# Mascot Asset Generation Prompts — PupLearn V1

## Global Rules for All Mascot Assets
- style: soft 3D toy world
- audience: children age 3–7
- look: cute, premium, rounded, warm, original
- polished 3D illustration with soft lighting and shadows
- single character only
- transparent background PNG
- full body visible, centered, enough padding
- no text
- no logo
- no extra props unless requested
- consistent visual family across all 4 mascots
- easy to recognize at small size

Do not imitate any existing entertainment franchise.

## Character Definitions
### Bingo
- golden retriever puppy
- yellow / warm golden palette
- Thai reading and understanding guide
- warm, patient, helpful

### Peter
- border collie puppy
- black and white with purple accents
- logic and analytical thinking guide
- curious, clever, thoughtful

### A-Chi
- corgi puppy
- orange / white with orange accents
- math / counting / money guide
- cheerful, energetic

### Pillow
- beagle puppy
- brown / white with blue accents
- English usage guide
- playful, friendly, confident

## Recommended Workflow
1. Generate the 8 mascot assets first.
2. Review them as a set for consistency.
3. If one character feels visually off, regenerate that character before moving to product assets.
4. Only after the mascot set is approved, continue to product assets.
