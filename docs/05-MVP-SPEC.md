# Supermarket MVP Specification

## MVP Goal
Build one complete playable vertical slice of the Supermarket world.

## Core Flow
1. Enter Supermarket
2. Mascot introduces mission
3. Child receives instruction
4. Child selects / drags products
5. Basket updates
6. Budget or rule is checked
7. Child receives hint if needed
8. Final English interaction
9. Mission Complete
10. Progress saved for parent

## MVP Content
- 1 World: Supermarket
- 15–20 mission templates
- 20–30 reusable product assets
- Thai voice instructions
- Simple English recognition
- Basic adaptive difficulty
- Parent progress summary

## Do Not Build Yet
- Multiplayer
- School dashboard
- Voice recognition
- Native mobile apps
- Complex rewards economy
- Multiple worlds
