# PupLearn Visual Design System V2

## Status
This document defines the new North Star visual direction for PupLearn.

## North Star
Reference image: `/docs/reference/visual-v2-north-star.png`

The target is a polished children's game interface, not a generic educational web app.

## Core Visual Direction
- Soft 3D Toy World
- Bright, cheerful, premium
- Rounded shapes
- Strong visual hierarchy
- Large expressive mascots
- Illustrated environments
- Minimal visual clutter
- Mobile-first

## Emotional Goal
The app should feel like a playful adventure, a friendly toy world, and a real game children want to explore.

It should NOT feel like an admin dashboard, worksheet, quiz form, or generic web-card interface.

## Typography
- Thai: Anuphan
- English / display / mascot names: Fredoka
- Large, readable, rounded
- Avoid dense text blocks

## Color System
- Bingo / Thai: warm yellow / orange
- Peter / Logic: purple
- A-Chi / Math: orange
- Pillow / English: blue
- Success: friendly green
- Base background: light sky blue / warm cream depending on scene

## UI Components
### Buttons
- Large rounded/pill shape
- Soft 3D depth
- Visible pressed state
- Subtle shadow
- Primary Level A CTA may pulse 1–2 times

### Cards
- Strongly rounded
- Soft shadow
- Warm white / cream
- Clear internal spacing
- Avoid excessive borders

### Mascot Speech Bubble
- Mascot should feel part of the scene
- Reusable component
- Stable mascot position
- Bubble may grow without pushing mascot position

### Progress
For Level A use visual dots / path nodes instead of text-heavy progress.

## Environment Principle
Each mission should have environmental context, such as supermarket exterior, fruit stand, toy shelf, checkout counter, picnic table, or play table.

Environment should support the mission, not distract from it.

## Product Assets
- Transparent PNG
- Soft 3D
- Single object
- No text baked into artwork
- Clear silhouette
- Consistent lighting and camera

## Mascot Assets
V2 may require additional poses: guide, pointing, celebrating, thinking, speaking, and interacting with mission objects.

## Animation Rules
Use animation to explain cause and effect.

Good:
- object bounces when tapped
- item flies into basket
- active vocabulary object pulses
- button gently pulses
- short star celebration

Avoid:
- constant flashing
- excessive particles
- distracting looping animation

## Core Rule
Learning clarity > decoration, but V2 should feel like a GAME, not merely a learning interface.
