# PupLearn Screen Templates V2

## Goal
Create visual variety while keeping interaction patterns understandable for young children.

## 1. World / Home Screen
- Large mascot hero
- Illustrated Supermarket environment
- Large Play CTA
- Minimal parent controls

## 2. Mission Selection
- Illustrated mission cards
- Strong mission icon/object
- Completion state
- Clear Level grouping
- Less empty space than V1

## 3. Mission Intro
- Environmental background
- Bingo larger and more expressive
- Speech bubble
- Mission object/context may appear in scene
- Large Start button
- Avoid a giant empty white card

## 4. Find One
- Supermarket shelf/display scene
- 4 large objects
- Basket visible
- Mascot integrated into scene
- Tap → reaction → correct item moves into basket

## 5. Color Hunt
- 4 objects, 4 distinct colors for beginner mode
- Play-table / shelf layout rather than standard cards
- One correct answer in beginner mode
- No scrolling
- English screen uses a solid color swatch, not only the selected object

## 6. Pick Two
- Display table / fruit stand
- Basket is central
- Two empty visual slots
- Progress visually obvious
- Objects placed naturally rather than identical grid cards

## 7. Vocabulary Teaching
ONE word = ONE active image.

Flow:
1. Show one object prominently
2. Pillow speaks slowly
3. Object pulses
4. Replay button
5. Move to next word if needed

Never show two equally prominent objects while teaching one word.

## 8. Success
- Mascot celebration
- Soft 3D star / sparkles
- Environmental continuity
- Clear Next Mission CTA
- Smaller Replay option
- No coins, streaks, loot, or addictive reward loops

## Shared V2 Rule
Do not force every mission into the same header → white card → grid → basket → success structure.
Use reusable interaction logic with different presentation templates.
