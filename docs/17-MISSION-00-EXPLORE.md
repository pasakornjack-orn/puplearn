# Mission 00 — Explore: Find the Apple

## Purpose
Validate that PupLearn can be enjoyable and understandable for a 3-year-old who cannot yet read.

## Level
A — Explore

## Learning Goal
Listen → Recognize → Tap → See Result → Learn Word

## Mission
Bingo asks the child to find the apple.

Thai instruction:
"ช่วย Bingo หาแอปเปิลหน่อย!"

## Flow
1. Bingo appears and gives the instruction.
2. The primary CTA gently pulses or bounces 1–2 times.
3. Child enters the Supermarket.
4. Show 4 large familiar objects:
   - Apple
   - Banana
   - Soap
   - Toothbrush
5. No prices.
6. No budget.
7. No text reading required.
8. Child taps any object.

## Exploration Behavior
If the child taps a non-target object:
- do NOT show a harsh wrong state
- animate the object gently
- optionally name the object
- allow continued exploration

Example:
Child taps Soap:
"นี่คือสบู่"

Then Bingo gently reminds:
"ลองหาแอปเปิลดูนะ"

## Correct Selection
When Apple is tapped:
1. Apple visually moves into a recognizable toy basket.
2. Bingo celebrates briefly.
3. Pillow introduces:
   "Apple!"
4. Child can tap the apple/speaker to hear "Apple" again.
5. Mission Complete.

## Basket UX
Use a visually recognizable basket, not a generic rectangle.
The child should see the selected object move into it.

## Interaction Rules
- large touch targets
- tap-first
- no precision drag required
- no reading dependency
- no math
- no negative feedback
- curiosity is allowed

## Session Target
Approximately 30–90 seconds.
