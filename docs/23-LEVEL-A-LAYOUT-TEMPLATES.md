# Level A Layout Templates

## Goal
Avoid visual repetition while keeping interaction familiar.

## Template 1 — Find One Grid
Use for:
- Find Apple
- Find Banana
- Find Ball

Layout:
- 4 large cards
- 2x2 grid
- toy basket visible

## Template 2 — Color Hunt
Use for:
- Find Something Red
- Find Something Blue

Layout:
- 6 objects
- looser shelf / play-table layout
- not strict identical cards
- show different object categories
- emphasize visual color recognition

## Template 3 — Pick Two
Use for:
- Pick 2 Fruits
- Pick 2 Toys

Layout:
- 4–6 objects
- persistent basket
- selected count shown visually, e.g. 1/2 or two basket slots
- no arithmetic teaching required

## Template 4 — Category Shelf
Use for:
- Find Fruit
- Find Toy
- Find Bathroom Item

Layout:
- objects arranged like toy shelves
- use gentle section framing
- no labels required for child success

## Template 5 — Compare
Use later for:
- Big vs Small
- Same vs Different

Layout:
- 2 or 3 large objects
- focus on visual comparison
- no basket required if it does not fit the mission

## Shared Rule
Do not force every mission to use:
intro → 2x2 grid → basket → Pillow → success

Use the same learning system but vary the visual presentation.
