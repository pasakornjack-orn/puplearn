# PupLearn — Product Vision

## Product
Real-Life Learning web app for children aged 3–7.

## Core Idea
Children learn through real-life missions instead of isolated quizzes.

## Core Learning Loop
Learn → Understand → Think → Apply

## Core Skills
1. Thai Reading / Understanding Instructions
2. Logical & Analytical Thinking
3. Math / Counting / Money
4. English Usage

## Positioning
A playful real-life learning experience that helps children “คิดเป็น ใช้เป็น”.

## Not This
- Not exam cramming
- Not worksheet-style learning
- Not a quiz app
- Not designed to maximize screen time

## First World
Supermarket

## Target Session
5–8 minutes per mission.
