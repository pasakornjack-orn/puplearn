# Supermarket Screen Flow

## 1. Parent Start
Parent opens app and selects child profile.

## 2. Child Home
Show mascot team and available world.

Primary CTA:
"ไป Supermarket กัน!"

## 3. World Entry
Short animated transition into the Supermarket.

## 4. Mission Intro
Bingo presents the instruction.
- Thai text
- Audio button
- Large visual mission card

## 5. Shopping Screen
Main child interaction screen.

Elements:
- Product shelves
- Basket
- Budget display when relevant
- Hint button
- Mascot guide
- Minimal navigation

## 6. Basket Review
Show selected items clearly.
For budget missions:
- Budget
- Total
- Remaining amount

## 7. English Check
Pillow asks one short English question.

Example:
"What did you buy?"

Child answers by tapping a visual/text choice.

## 8. Mission Complete
- Brief celebration
- Mascot reaction
- Simple achievement feedback
- CTA: "เล่นอีกภารกิจ"
- CTA: "พักก่อน"

## 9. Parent Summary
After child mode ends:
- Missions completed
- Thai
- Logic
- Math
- English
- Short parent-friendly observation

## UX Rule
The child should never need to navigate complex menus during a mission.
